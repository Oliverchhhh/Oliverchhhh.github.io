前几天花了些时间，给我们团做了一个网站：[浙江大学研究生支教团（新疆阿克苏分团）](https://zjuvtc.netlify.app/)。

## 做了什么

整个网站是纯静态的，没有用任何框架，HTML + CSS + JS 手写，部署在 GitHub Pages 上。页面包括首页（新闻动态）、团队成员、品牌活动、赞助公示和联系我们。

设计上参考了学校官网的风格，用网格线结构和单一强调色（深绿）,整体上强调简洁。

## 解决的核心问题

团里成员背景多元，其他成员没办法直接改 Markdown 或提 PR。所以接入了 [Decap CMS](https://decapcms.org)，做了一个可视化后台。成员在浏览器里填表、上传图片、点发布，内容就自动 commit 到 GitHub 仓库，部署平台同步更新。

认证方面用了 Netlify Identity，支持 GitHub 账号和邮箱密码两种登录方式，方便不同背景的成员使用。

## 一些小细节

- 实现了cc98式的 rich text + Markdown 编辑器
- 在以上基础上，在编辑界面实现了实时预览

总体来说是个很适合小型组织的轻量方案，维护成本几乎为零。
